# Icon source

Keep `icon.svg` **or** `icon.png` here. PNG must be a still, square **1024 x 1024** image; color and transparency are supported.

If both files exist, the build stops until you remove one or choose explicitly with `./apk.ps1 -Release -IconSource assets/icon/icon.png` (or `.svg`).

See [full requirements and build instructions](../../docs/ICONS.md).
